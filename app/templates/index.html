Frequently asked questions

What file formats can I upload?

CSV, Excel (.xlsx / .xls), and JSON. Up to 100 MB per file. For larger datasets, split the file or extract a subset before uploading.

What's the maximum file size?

100 MB per upload. Above that, browser memory becomes the bottleneck — for very large datasets, split the file. Polars-based streaming for 1 GB+ files is on the roadmap.

How long is my data kept?

24 hours from your last activity. After that it's automatically deleted. Files are stored per-browser-session, never shared between users, and never sent to a third party.

How does the tool decide which imputation method to use?

It profiles each column: missingness percentage, dtype, cardinality, distribution skew, and correlation with other columns. Numeric with low skew gets mean; skewed gets median; correlated numeric gets KNN; categorical gets mode. You can always override the suggestion — nothing runs without your confirmation.

What's the difference between KNN, MICE, and mean imputation?

Mean replaces missing values with the column average — fast, but ignores relationships between columns and shrinks variance. KNN finds similar rows and averages their values — good when columns correlate. MICE iteratively models each column from the others — slowest but statistically strongest. When in doubt, use MICE for analysis, KNN for ML training.

Can I reuse the same cleaning steps on new data?

Yes. After preprocessing, click Export pipeline. You get a YAML file describing every choice. On the home page, upload any new CSV plus that YAML — DataForge applies the identical recipe using the fitted parameters from your original run. No re-selecting anything, no train/test leakage.

Is this really training/test-leakage safe?

Yes for pipelines applied via the YAML workflow. When you export a pipeline, we save the fitted state (means, KNN models, MICE coefficients). When you re-apply it, we reuse those instead of re-fitting on the new data. That's the correct way to do it — the same approach production ML systems use.

Can I run SQL against my uploaded file?

Yes — click SQL in the top navigation. Your dataset is available as the table df. You can write any SELECT or WITH query, including GROUP BY, JOIN, window functions, and CTEs. Results render as a table and export to CSV or JSON.

Is it safe to run SQL here?

Yes. Only SELECT and WITH statements are allowed. Statements like DROP, DELETE, COPY, and ATTACH are blocked, and external file access is disabled at the database level. You cannot read or write files on the server.

Can I pivot data like in Excel?

Coming next. The Pivot page will let you pick row columns, column columns, value columns, and an aggregation — one-click pivot tables. In the meantime, the SQL page supports pivots via GROUP BY and conditional aggregation.

Do I need to install anything to use this?

No. DataForge runs entirely in your browser once it's running on a server. You only need Python if you're self-hosting the tool.

Is my data used to train any model?

No. Your data is never used for training, never shared, never logged to an external service. It lives on the server for 24 hours and is then deleted. If you self-host, it never leaves your machine.

Where can I report bugs or request features?

Open an issue on GitHub. Same for pull requests — the tool is fully open source.
